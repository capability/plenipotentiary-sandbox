# MCP Pattern Usage Example

Complete walkthrough of the MCP filesystem implementation.

---

## Setup

### 1. Install MCP Filesystem Server

```bash
npm install -g @modelcontextprotocol/server-filesystem
```

### 2. Configure MCP in Laravel

Add to your `config/mcp.php` (or publish the config):

```php
return [
    'servers' => [
        'filesystem' => [
            'transport' => 'stdio',
            'command' => 'npx',
            'args' => [
                '-y',
                '@modelcontextprotocol/server-filesystem',
                storage_path('logs'), // Allowed directory
            ],
        ],
    ],

    'agent_budgets' => [
        'default' => [
            'daily_limit' => 10.00,  // $10 per day
        ],
        'log-analyzer' => [
            'daily_limit' => 5.00,   // $5 per day
        ],
    ],
];
```

### 3. Register Service Provider

In `config/app.php`:

```php
'providers' => [
    // ...
    \Plenipotentiary\Laravel\Pleni\MCP\Providers\McpServiceProvider::class,
],
```

## Example 1: Direct Tool Call

### Read a File

```php
use Plenipotentiary\Laravel\Pleni\MCP\Contexts\Default\Actions\CallToolAction;

$action = app(CallToolAction::class);

$result = $action->handle(
    server: 'filesystem',
    tool: 'read_file',
    arguments: ['path' => storage_path('logs/laravel.log')],
    agentId: 'my-agent'
);

if ($result->isOk()) {
    $content = $result->unwrap()->asText();
    echo "File content:\n{$content}";
} else {
    $error = $result->error();
    echo "Error: {$error['message']}";
}
```

### List Directory

```php
$result = $action->handle(
    server: 'filesystem',
    tool: 'list_directory',
    arguments: ['path' => storage_path('logs')],
    agentId: 'file-browser'
);

if ($result->isOk()) {
    $files = $result->unwrap()->asArray();
    print_r($files);
}
```

### Write a File

```php
$result = $action->handle(
    server: 'filesystem',
    tool: 'write_file',
    arguments: [
        'path' => storage_path('logs/agent-output.txt'),
        'content' => 'Generated by AI agent at ' . now(),
    ],
    agentId: 'content-generator'
);

if ($result->isOk()) {
    $meta = $result->unwrap()->meta;
    echo "Wrote {$meta['bytes_written']} bytes";
}
```

## Example 2: Multi-Step Agent Workflow

### Log Analyzer Agent

```php
use Plenipotentiary\Laravel\Pleni\MCP\Examples\LogAnalyzerAgent;

$agent = new LogAnalyzerAgent(
    mcpTool: app(CallToolAction::class),
    agentId: 'log-analyzer'
);

// Analyze all logs in directory
$result = $agent->analyzeLogs(storage_path('logs'));

if ($result->isOk()) {
    $report = $result->unwrap()->asArray();

    echo "Analyzed {$report['summary']['files_analyzed']} files\n";
    echo "Found {$report['summary']['total_errors']} errors\n";
    echo "Found {$report['summary']['total_warnings']} warnings\n";

    foreach ($report['recommendations'] as $recommendation) {
        echo "- {$recommendation}\n";
    }
}
```

**What this does:**
1. Lists all `.log` files in directory
2. Reads each file
3. Analyzes for ERROR/WARNING patterns
4. Generates summary report
5. Writes report to `analysis-report.json`

**Budget tracking:**
- Each file read costs ~$0.01
- Report generation costs ~$0.01
- Total cost tracked per agent per day

## Example 3: Controller Endpoint

```php
// routes/api.php
use Plenipotentiary\Laravel\Pleni\MCP\Contexts\Default\Actions\CallToolAction;
use Illuminate\Http\Request;

Route::post('/mcp/call', function (Request $request, CallToolAction $action) {
    return $action->asController($request);
});
```

**Request:**
```bash
curl -X POST http://localhost/api/mcp/call \
  -H "Content-Type: application/json" \
  -d '{
    "server": "filesystem",
```

## Example 4: Artisan Command

```php
// app/Console/Commands/McpCallCommand.php
use Illuminate\Console\Command;
use Plenipotentiary\Laravel\Pleni\MCP\Contexts\Default\Actions\CallToolAction;

class McpCallCommand extends Command
{
    protected $signature = 'mcp:call
                           {server : MCP server name}
                           {tool : Tool name}
                           {arguments? : JSON arguments}
                           {--agent=cli : Agent ID}';

    protected $description = 'Call an MCP tool';

    public function handle(CallToolAction $action): int
    {
        return $action->asCommand($this);
    }
}
```

**Usage:**
```bash
# Read a file
php artisan mcp:call filesystem read_file '{"path":"/storage/logs/laravel.log"}' --agent=admin

# List directory
php artisan mcp:call filesystem list_directory '{"path":"/storage/logs"}' --agent=admin

# Write a file
php artisan mcp:call filesystem write_file '{"path":"/tmp/test.txt","content":"Hello World"}' --agent=admin
```

## Example 5: Queued Job

```php
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Plenipotentiary\Laravel\Pleni\MCP\Contexts\Default\Actions\CallToolAction;

class AnalyzeLogsJob implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public function __construct(
        private string $logPath,
    ) {}

    public function handle(CallToolAction $action): void
    {
        $action->asJob(
            server: 'filesystem',
            tool: 'read_file',
            arguments: ['path' => $this->logPath],
            agentId: 'async-analyzer'
        );
    }
}

// Dispatch job
AnalyzeLogsJob::dispatch(storage_path('logs/laravel.log'));
```

## Budget & Rate Limiting

### Check Agent Budget

```php
use Plenipotentiary\Laravel\Pleni\MCP\Shared\Support\AgentBudgetTracker;

$tracker = app(AgentBudgetTracker::class);
$usage = $tracker->getUsage('log-analyzer');

echo "Daily cost: \${$usage['daily_cost']}\n";
echo "Calls made: {$usage['call_count']}\n";
echo "Remaining: \${$usage['remaining']}\n";
```

### Reset Agent Budget

```php
$tracker->reset('log-analyzer');
```

### Budget Exceeded Error

When an agent exceeds budget:

```json
{
  "error": "AGENT_BUDGET_EXCEEDED",
  "message": "Agent 'log-analyzer' has exceeded daily budget",
  "usage": {
    "daily_cost": 5.00,
    "call_count": 487,
    "limit": 5.00,
    "remaining": 0
  }
}
```

## Error Handling

### File Not Found

```php
$result = $action->handle(
    server: 'filesystem',
    tool: 'read_file',
    arguments: ['path' => '/nonexistent/file.txt'],
    agentId: 'my-agent'
);

// $result->isErr() === true
// $result->error() === [
//     'error' => 'MCP_TOOL_ERROR',
//     'message' => 'File not found: /nonexistent/file.txt',
//     'code' => 'FILE_NOT_FOUND'
// ]
```

### Access Denied

```php
$result = $action->handle(
    server: 'filesystem',
    tool: 'read_file',
    arguments: ['path' => '/etc/passwd'], // Outside allowed roots
    agentId: 'my-agent'
);

// $result->error() === [
//     'error' => 'MCP_TOOL_ERROR',
//     'message' => "Path '/etc/passwd' is not within allowed directories",
//     'code' => 'ACCESS_DENIED'
// ]
```

### Server Not Found

```php
$result = $action->handle(
    server: 'unknown-server',
    tool: 'some_tool',
    arguments: [],
    agentId: 'my-agent'
);

// $result->error() === [
//     'error' => 'MCP_SERVER_NOT_FOUND',
//     'message' => "MCP server 'unknown-server' not configured",
//     'available_servers' => ['filesystem']
// ]
```

## Testing

```php
use Tests\TestCase;
use Plenipotentiary\Laravel\Pleni\MCP\Contexts\Default\Actions\CallToolAction;

class McpTest extends TestCase
{
    public function test_can_read_file_via_mcp(): void
    {
        // Create test file
        $testPath = storage_path('logs/test.log');
        file_put_contents($testPath, 'Test content');

        $action = app(CallToolAction::class);

        $result = $action->handle(
            server: 'filesystem',
            tool: 'read_file',
            arguments: ['path' => $testPath],
            agentId: 'test-agent'
        );

        $this->assertTrue($result->isOk());
        $this->assertEquals('Test content', $result->unwrap()->asText());

        // Cleanup
        unlink($testPath);
    }

    public function test_budget_limits_are_enforced(): void
    {
        // Set low budget for test
        config(['mcp.agent_budgets.test-agent.daily_limit' => 0.02]);

        $action = app(CallToolAction::class);

        // First call succeeds
        $result1 = $action->handle(
            server: 'filesystem',
            tool: 'list_directory',
            arguments: ['path' => storage_path('logs')],
            agentId: 'test-agent'
        );
        $this->assertTrue($result1->isOk());

        // Second call may succeed

        // Third call should fail (budget exceeded)
        $result3 = $action->handle(
            server: 'filesystem',
            tool: 'list_directory',
            arguments: ['path' => storage_path('logs')],
            agentId: 'test-agent'
        );

        if ($result3->isErr()) {
            $this->assertEquals('AGENT_BUDGET_EXCEEDED', $result3->error()['error']);
        }
    }
}
```

## Summary

The MCP pattern provides:

✅ **Type-safe operations** - CallToolDTO, CallToolResult
✅ **Budget tracking** - Prevent runaway costs
✅ **Rate limiting** - Prevent agent loops
✅ **Error handling** - Graceful degradation
✅ **Observability** - Complete audit trail
✅ **Laravel integration** - Actions, Jobs, Commands, Controllers
✅ **Security** - Path restrictions, access controls

**It works seamlessly with existing Plenipotentiary patterns!**
